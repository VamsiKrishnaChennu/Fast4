# Dictionary sources

The local dictionary judges every answer instantly. The four lists live in `server/data/dictionary/` (`names.txt`, `places.txt`, `animals.txt`, `things.txt`), one lower-case word per line. They are generated by `npm run dictionary:build`, committed, and loaded into MongoDB by `npm run dictionary:seed -- --replace`. The server loads them at start-up, so restart it after seeding.

Lookups ignore spaces, hyphens and apostrophes ("Tamilnadu" finds "Tamil Nadu"), and a word may be in several lists ("kite" is an animal and a thing).

## Build options

`npm run dictionary:build` is strict: if SSA, Wikidata names, Wikidata places or WordNet gives nothing, it stops with exit code 1 and writes nothing. Options: `--allow-fallback` (build from the curated lists anyway), `--only=names,places` (rebuild some lists), `--refresh` (ignore cached Wikidata answers), `--no-wikidata-things`, `--accept-large-places` (places.txt over 15 MB). If ssa.gov blocks the download, save the file as `server/data/dictionary/downloads/names.zip`; if the Open English WordNet download fails, save it as `downloads/oewn-2024.xml.gz`. The `downloads` folder is not committed.

## Rules applied to every list

- Accents are folded first (Ümit becomes umit). Labels that still contain other scripts, digits or symbols, or that start with a non-letter, are skipped. Place labels need 3 letters and must look like a name.
- Every line is normalized with `normalizeAnswer` (a to z, space, hyphen, apostrophe), 2 to 30 characters.
- Entries are de-duplicated, sorted, and run through the `bad-words` profanity filter. The filter also removes some real words (ass, tit, cock, screw, pawn); the build prints every removal. Add real words back through the curated lists only after checking `starter/blocked.txt` rules.
- Things: WordNet nouns under physical entity and artifact, minus animal, person, location and physical process synsets. No comparison with the other lists.
- Typing a plural also works ("tigers" finds "tiger", "icecreams" finds "ice cream").
- To keep a word out for good, add a line such as `animal: animal` to `server/data/dictionary/starter/blocked.txt`.
- The curated lists in `server/data/dictionary/starter/` can be edited by hand. Commas or new lines separate entries, and lines starting with `#` are notes.
