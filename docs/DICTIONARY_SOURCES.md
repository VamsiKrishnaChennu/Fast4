# Dictionary sources

The local dictionary judges every answer instantly. The four lists live in `server/data/dictionary/` (`names.txt`, `places.txt`, `animals.txt`, `things.txt`), one lower-case word per line. They are generated by `npm run dictionary:build`, committed, and loaded into MongoDB by `npm run dictionary:seed`.

## Current lists (built 31 Oct 2026 in the build sandbox)

| List    | Words  | Minimum | Sources used in this build                                                                                                                                                                              |
| ------- | ------ | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| names   | 7,697  | 5,000   | NLTK names list (Mark Kantrowitz, public domain); curated international and Indian first names                                                                                                          |
| places  | 1,022  | 10,000  | **STARTER DATA ONLY.** Country and capital names from the `world-countries` package; curated Indian, US, Canadian, Australian, UK and world places, rivers, lakes, seas, mountains, islands and deserts |
| animals | 4,714  | 1,500   | WordNet 3.1: every noun under animal.n.01; curated common animals                                                                                                                                       |
| things  | 32,044 | 10,000  | WordNet 3.1: nouns under physical_entity.n.01 and artifact.n.01, minus animals, people, locations and names/places/animals; curated everyday things                                                     |

**Owner action required:** the build sandbox could not reach Wikidata or the US Social Security Administration. Run `npm run dictionary:build` once on a machine with internet access to add the Wikidata place list (target 10,000+ places) and the SSA baby names, then review the changes and commit the regenerated files. The build script reports which sources it reached. If a Wikidata query times out the script retries with a smaller page size.

## Rules applied to every list

- Every line is normalized with `normalizeAnswer` (a to z, space, hyphen, apostrophe), one or two words, 2 to 30 characters.
- Entries are de-duplicated, sorted, and run through the `bad-words` profanity filter.
- Typing a plural also works: the validator tries the singular forms of the last word ("tigers" finds "tiger", "horses" finds "horse").
- The curated lists in `server/data/dictionary/starter/` can be edited by hand. Commas or new lines separate entries, and lines starting with `#` are notes.
