# Dictionary data

Generated by `npm run dictionary:build`; see `docs/DICTIONARY_SOURCES.md` for sources, counts and licenses (including the WordNet and Open English WordNet notices). Edit the curated lists in `starter/`, not the four generated files.

Rebuild and reload (needs internet, takes a while the first time because of Wikidata):

1. `npm run dictionary:build` and read the per-source table. Look at the printed word samples; rebuild with `--no-wikidata-things` if they look noisy.
2. `npm run dictionary:seed -- --replace` (adds new words, removes old seed words that are gone, keeps words won on appeal).
3. Restart the server: the dictionary is loaded only at start.
4. `npm run dictionary:coverage` (no database needed) and `npm run dictionary:diagnose` (read-only report) to check the result.

`downloads/` holds cached downloads and is not committed. If ssa.gov blocks the build, save the file as `downloads/names.zip`.
